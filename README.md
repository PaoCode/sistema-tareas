# Sistemas de tareas 
Aplicación de escritorio creada con **Java** y el conjunto de herramientas de **Java FX** logrando una interfaz sencilla y moderna.
Esta aplicación permite la gestión y asignación de tareas.

## Funcionalidades
- Agregar tareas asignadolas a un responsable y con su estatus.
- Modificar la tarea, el responsable o estatus.
- Eliminar la tarea.
- Limpiar el formulario.
- Contiene mensajes de confirmación de cada una de las acciones.

## Requisitos
- Java 21
- Spring Boot 3.5.7
- MySql

## Instalación
- Clonar el repositorio 
- Abrir el proyecto en tu IDE favorito
- Configurar la base de datos MySQL

## Ejecución
- Seleccionar la clase TareasApplication(src/main/java/gm.tareas/TareasApplication)
- Ejecutar la aplicación
